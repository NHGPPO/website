# nhgppo.co.uk

Website for Northern Health GPPO (NHGPPO Ltd), built by Systemwork. Astro static site on Netlify.

- `npm install`, then `npm run dev` to work locally.
- `npm run build` builds into `dist/` and runs the gate (`scripts/gate.mjs`). A failing gate fails the Netlify deploy.
- Rules and how to ship: see `CLAUDE.md`.
